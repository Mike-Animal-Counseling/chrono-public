# Chrono — Temporal Decision Workspace

Replay the past. Understand the present. Rehearse and forecast the future.

Chrono is an event-sourced decision workspace for teams that ship software. Every change is stored as an immutable event; boards, timelines, diffs, scenarios, forecasts, and AI explanations are projections of the same event stream at different points in time.

## What you can do

- **Replay** — scrub to any moment in a project's history and see the board exactly as it was.
- **Compare** — structured, event-level diff between any two points in time.
- **Rehearse** — branch into a scenario, test staffing or scope changes, apply back when satisfied.
- **Forecast** — deterministic delivery projection: capacity-aware scheduling, critical path, risk rating.
- **Ask AI** — evidence-grounded explanations over the event trail, via any OpenAI-compatible provider.
